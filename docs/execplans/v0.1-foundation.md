## Time, identity, and timeline model

Use safe integer milliseconds, half-open ranges `[startMs, endMs)`, and unit playback speed. Source times are relative to each asset's normalized presentation origin. Timeline times start at zero. Convert external timestamps once, explicitly record rounding and the stream origin mapping, and never accumulate floating-point seconds during editing. Actual rendering remains bounded by source frame/audio timing; report those tolerances instead of treating millisecond arithmetic as frame-exact output.

V0.1 supports one source asset, one sequence, and one linked audiovisual lane. Each clip maps a source interval to a timeline interval of equal duration. Audio and video move together. No overlapping clips, mixing, transitions, speed changes, or separate audio edits. Timeline duration is the largest clip end, including gaps; an empty candidate has duration zero. Render gaps as black with silence so `delete` and `ripple_delete` have visibly different meanings. Empty candidates can exist and be undone, but cannot be rendered or promoted.

Identifiers are opaque stable strings. Asset IDs derive from source-byte hashes; transcript segment IDs derive deterministically from asset ID, transcript digest, cue index, and normalized interval. Preserve segment identity through edits. Timeline clip identity is separate from source segment identity. Kernel-created clip IDs derive from operation IDs and output position; retries cannot create duplicates. A split retires the parent ID and returns a parent-to-child mapping. Callers must retrieve updated IDs rather than submit stale references.

## Proposed TypeScript/Zod schema contract

The following is the minimum schema outline for `packages/core/src/schemas.ts`. Infer TypeScript types from Zod schemas rather than maintaining two definitions. All object schemas are strict; parse every external request and persisted artifact. Context-dependent rules belong to the kernel or ingestion validator, not just field-level schemas.

```ts
import { z } from 'zod';

const Id = z.string().min(1);
const Ms = z.number().int().nonnegative().max(Number.MAX_SAFE_INTEGER);
const PositiveMs = Ms.refine(value => value > 0);
const Digest = z.string().regex(/^[a-f0-9]{64}$/);
const Range = z.object({ startMs: Ms, endMs: Ms }).strict()
  .refine(value => value.endMs > value.startMs, 'non-empty half-open range');
const SourceRef = z.object({ assetId: Id, range: Range }).strict();

const SourceAsset = z.object({
  id: Id,
  contentHash: Digest,
  mediaPath: z.string().min(1), // trusted relative project path; never an agent input
  durationMs: PositiveMs,
  video: z.object({
    streamIndex: Ms, width: PositiveMs, height: PositiveMs,
    frameRate: z.object({ numerator: PositiveMs, denominator: PositiveMs }).strict(),
    variableFrameRate: z.boolean(),
  }).strict(),
  audio: z.object({ streamIndex: Ms, sampleRate: PositiveMs, channels: PositiveMs })
    .strict().optional(),
  presentationOriginUs: z.number().int().min(Number.MIN_SAFE_INTEGER)
    .max(Number.MAX_SAFE_INTEGER),
}).strict();

const MediaSegment = z.object({
  id: Id, assetId: Id, sourceRange: Range, transcriptText: z.string(),
  speaker: z.string().optional(), summary: z.string().optional(),
  tags: z.array(z.string()).default([]),
}).strict();

const TimelineClip = z.object({
  id: Id, assetId: Id, sourceRange: Range, timelineStartMs: Ms,
}).strict();

const SourceRequirement = z.object({
  id: Id, description: z.string().min(1),
  ranges: z.array(SourceRef).min(1), strength: z.enum(['hard', 'soft']),
}).strict();
const DurationTarget = z.object({ minMs: Ms, maxMs: PositiveMs }).strict()
  .refine(value => value.minMs <= value.maxMs);

const RunPolicy = z.object({
  schemaVersion: z.literal(1), id: Id, rawRequest: z.string().min(1),
  targetDuration: DurationTarget.optional(),
  requirements: z.array(SourceRequirement),
  allowedOperations: z.array(z.enum(['split', 'trim', 'delete', 'ripple_delete', 'move'])),
}).strict();

const ProjectIR = z.object({
  schemaVersion: z.literal(1), id: Id,
  assets: z.array(SourceAsset).length(1),
  transcriptHash: Digest, segments: z.array(MediaSegment),
  sequence: z.object({ id: Id, clips: z.array(TimelineClip) }).strict(),
  policy: RunPolicy,
}).strict();

const IntentItem = z.object({
  description: z.string().min(1),
  ranges: z.array(SourceRef), // empty means semantic/unbound; no invented source binding
}).strict();
const EditContract = z.object({
  schemaVersion: z.literal(1), id: Id, policyId: Id,
  objective: z.string().min(1), targetDuration: DurationTarget.optional(),
  preserve: z.array(IntentItem), protect: z.array(IntentItem),
  allow: z.array(z.string()), avoid: z.array(z.string()),
  autonomy: z.enum(['propose_only', 'edit_candidate']),
  successCriteria: z.array(z.object({
    id: Id, description: z.string().min(1), kind: z.enum(['deterministic', 'semantic']),
  }).strict()),
}).strict();

const EditorialPlan = z.object({
  schemaVersion: z.literal(1), id: Id, contractId: Id, baseContentHash: Digest,
  selectedSegments: z.array(Id), removedSegments: z.array(Id),
  reorderings: z.array(z.object({ segmentId: Id, beforeSegmentId: Id.nullable() }).strict()),
  rationale: z.string(), unresolvedQuestions: z.array(z.string()),
  estimatedDurationMs: Ms,
}).strict();

const operationFields = { operationId: Id };
const EditOperation = z.discriminatedUnion('type', [
  z.object({ ...operationFields, type: z.literal('split'),
    clipId: Id, atSourceMs: Ms }).strict(),
  z.object({ ...operationFields, type: z.literal('trim'),
    clipId: Id, sourceRange: Range }).strict(),
  z.object({ ...operationFields, type: z.literal('delete'), clipId: Id }).strict(),
  z.object({ ...operationFields, type: z.literal('ripple_delete'), clipId: Id }).strict(),
  z.object({ ...operationFields, type: z.literal('move'),
    clipId: Id, destinationTimelineStartMs: Ms }).strict(),
]);

const EditBatch = z.object({
  schemaVersion: z.literal(1), batchId: Id,
  workspaceId: Id, expectedRevision: Ms,
  operations: z.array(EditOperation).min(1),
}).strict();

const SnapshotRef = z.object({ revision: Ms, contentHash: Digest }).strict();
const AgentWorkspace = z.object({
  schemaVersion: z.literal(1), id: Id, projectId: Id,
  base: SnapshotRef, head: SnapshotRef, policyHash: Digest,
  state: z.enum(['open', 'committed', 'discarded']),
  undoReceiptIds: z.array(Id), redoReceiptIds: z.array(Id),
  candidateOperationBatches: z.array(EditBatch),
  editContract: EditContract.optional(), editorialPlan: EditorialPlan.optional(),
  previewIds: z.array(Id),
}).strict();

const VerificationResult = z.object({
  schemaVersion: z.literal(1), checkId: Id,
  kind: z.enum(['deterministic', 'model_assisted']),
  status: z.enum(['pass', 'fail', 'review']),
  evidence: z.array(z.object({
    message: z.string(), source: SourceRef.optional(),
    timelineRange: Range.optional(), artifactId: Id.optional(),
  }).strict()).min(1),
  confidence: z.number().min(0).max(1).optional(),
  evaluatedContentHash: Digest, policyHash: Digest,
}).strict();

type Project = z.infer<typeof ProjectIR>;
type Operation = z.infer<typeof EditOperation>;
type Contract = z.infer<typeof EditContract>;
type Plan = z.infer<typeof EditorialPlan>;
type Workspace = z.infer<typeof AgentWorkspace>;
type Check = z.infer<typeof VerificationResult>;
```

Use a single safe-integer primitive for numeric fields in this outline; give stream indices, dimensions, and rates domain-specific names in implementation. `ProjectIR` contains content, not mutable revision counters. Store it under canonical content hashes in a revision envelope. Define receipts as strict objects containing batch ID, operation payload digest, before/after snapshot references, created/retired clip mappings, and policy hash. Define a typed error union with `schema_invalid`, `stale_revision`, `invalid_reference`, `source_bounds`, `timeline_overlap`, `hard_constraint`, `operation_not_allowed`, `unsupported_media`, and `io_failure` codes plus contextual evidence.

Additional contextual validation must require unique IDs, resolvable references, sorted non-overlapping clip intervals, valid transcript ranges, safe computed clip ends, and requirements bound to the asset. Plan selections/removals must be disjoint and resolve to segments; reorderings must be unambiguous and acyclic. Plans need not classify every segment: omissions and unresolved questions must be made explicit by the future compiler. Its first version should resolve whole segment ranges, use stable ordering, and reject ambiguous overlap rather than invent edits.

`RunPolicy` is a proposed shared enforcement envelope, not an Intent Graph or another agent planner. It is initialized by trusted fixture setup and immutable during a run. AETHER-generated contracts cannot replace it, weaken protections, or grant operation permissions. Unbound semantic intentions stay unbound until resolved with evidence and review. Neither path may manufacture a binding and count it as ground truth.

## Editing kernel and five initial operations

Expose a pure internal function conceptually equivalent to:

```ts
applyBatch(project: Project, operations: readonly Operation[], policy: RunPolicy)
  -> { nextProject, clipMappings } | { error }
```

Workspace identity, revision checks, authorization, idempotency, and durable receipts are handled by the workspace service before and after this pure reducer. Kernel validation still independently checks the project's embedded policy against the supplied immutable policy. Do not accept a caller-provided replacement `ProjectIR` as an edit request.

| Operation | Precise V0.1 semantics |
| --- | --- |
| `split` | `atSourceMs` is strictly inside the addressed clip's source interval. Replace the parent with left/right children, preserving exact combined source coverage, duration, and timeline position. Return child IDs. Endpoint splits fail. |
| `trim` | New source interval must be a non-empty subset of the current interval. Keep the clip's timeline start unchanged and do not shift other clips. Shortening creates a trailing gap; a head trim changes which source plays at the existing start. No extension or implicit ripple. |
| `delete` | Remove the addressed clip while leaving every other timeline start unchanged. Interior deletion leaves a gap. Deleting the last clip reduces sequence duration to the remaining maximum end. |
| `ripple_delete` | Remove the addressed clip; shift every later clip left by the removed clip's duration, preserving any pre-existing gaps. Earlier clips retain their starts. Split first to delete a subrange. |
| `move` | Set the addressed clip's timeline start to an absolute nonnegative destination. Other clips retain their starts; source coverage and duration are unchanged. Reject overlap with any other clip. Reorder into occupied space by moving through a temporary free interval in an atomic batch; no implicit swap, overwrite, or ripple. |

Example fixture: clip A covers source/timeline `[0,1000)`, B covers `[1000,2000)`, and C covers `[2000,3000)`. Deleting B leaves C at 2000 and a 1000 ms gap; ripple-deleting B places C at 1000. Splitting A at source 400 produces `[0,400)` and `[400,1000)` at timeline 0 and 400. Trimming A to source `[200,800)` leaves its timeline start at zero and duration 600. Moving C to timeline 500 fails for overlap. An atomic swap may move A to a temporary unoccupied start, move B into A's vacated interval, and move A into B's vacated interval. These are explicit choices for review, not hidden compiler behavior.

Required invariants at initialization, after each provisional operation, on load, on undo/redo, and before promotion:

1. All schemas parse strictly; IDs are unique and all asset/clip/segment references resolve.
2. Source and clip durations are positive; timeline starts and computed ends are nonnegative safe integers. Empty timelines are allowed only as candidates.
3. Every source interval is within the probed normalized playable asset duration. No agent-supplied media paths or stream mappings.
4. Clips are sorted by timeline start with an ID tie-breaker, with no audiovisual overlaps. Gaps are explicit consequences of positions.
5. Every hard protected/required source interval remains fully covered by the union of candidate clip source intervals. Coverage across adjacent split clips counts; partial retention does not. Soft and semantic requirements are reported by verification. Coverage alone is not proof that meaning survives reordering.
6. The immutable common policy, media metadata, segment data, and source/transcript hashes cannot change through timeline operations.
7. Each operation is allowed by the common policy; every state change has a validated reversible receipt.
8. No model, tool caller, renderer, or verifier can write accepted timeline state directly.

Duration targets are final verification criteria rather than intermediate kernel invariants: a full-length initial project may exceed its requested target. Hard source protection applies to every provisional state. The initial full-source project must already cover all hard requirements, otherwise initialization fails. Run final verification on completed batches before preview/promotion and retain failures as evidence.

Treat a batch as atomic. Validate its external shape, then apply each operation to private provisional state, checking invariants after each operation. Publish one new candidate revision only when the entire batch succeeds. On any failure publish no revision, snapshot, or partial journal; record a rejected-attempt trace. A later operation may address deterministic children created by an earlier split in the same batch. Undo history stores the whole batch as one step. No-op operations return a documented no-change result and do not create a misleading applied-edit receipt.

## Media ingestion and bounded rendering

Ingestion is a trusted CLI action, not a timeline-edit tool. Input is a local video plus a UTF-8 timestamped transcript JSON file with `{ schemaVersion: 1, timeUnit: 'seconds' | 'milliseconds', cues: [{ start, end, text, speaker? }] }`. No transcription service is required. Preserve the raw transcript and its digest. Convert its times to normalized integer milliseconds, record the original units and origin, reject empty/out-of-bounds/overlapping or unordered cues in V0.1, and use cue boundaries as initial `MediaSegment` boundaries. Gaps between transcript cues are legal pauses; do not infer silence solely from text gaps. Do not generate summaries or semantic tags automatically for the foundation.

1. Validate a readable local input file and transcript, hash source bytes and transcript bytes, and store an immutable local source copy under a project-relative content-addressed path. Never overwrite an existing different asset.
2. Execute ffprobe with fixed argument arrays through `spawn` with `shell: false`; parse JSON format/stream metadata. Resolve the video stream and optional associated audio stream explicitly. Reject ambiguous stream choices rather than selecting silently. Record duration, dimensions, rates/timebases, presentation origin, stream indices, and binary versions in an ingestion manifest.
3. Normalize container/stream timestamps to a common zero origin while retaining relative A/V offsets. Reject missing/contradictory durations, unsupported rotation/HDR policies, unreadable media, or uncertain timestamp mappings with evidence. V0.1 initially targets ordinary SDR sources; unsupported media does not trigger silent transcoding.
4. Validate cue bounds against normalized source time. Build stable segment IDs and one full-duration linked clip. Bind any manually supplied trusted hard requirements and validate their coverage. Publish an accepted initial revision atomically only after all checks pass.
5. Keep assets, normalized transcript, project, and manifest locally. Re-ingesting identical bytes and settings should reuse or reproduce equivalent immutable content without duplicate segment IDs. Source hash changes require a new asset/project, never silent relinking.

Renderer input is a validated read-only project snapshot, a bounded timeline range for preview or the full sequence for rendering, and a fixed render preset. Compile a render recipe with per-clip source trims, presentation timestamp reset, linked audio trims, explicit gap black/silence, and concat in timeline order. Normalize streams to one deterministic preset with fixed resolution, frame rate, sample rate, codecs, and thread settings. Handle a missing audio stream by synthesizing silence. Use re-encoding rather than keyframe-constrained stream copy for arbitrary cuts. Treat a partial preview as an intersection with the requested timeline range, including gaps.

Only Media constructs FFmpeg arguments. Agents get no shell-string, arbitrary filter, output-path, codec, or executable parameter. Validate known paths, restrict outputs to the artifact directory, bound preview duration and subprocess runtime, and clean up failed temporary outputs. The CLI preflight should detect absent binaries and provide actionable errors, not download them automatically.

Record snapshot hash, source hash, preset, FFmpeg/ffprobe versions, source ranges, output path/digest, and measured output properties for every artifact. Probe completed renders to detect failed/empty output, duration drift, and A/V timing errors. Use a declared integration tolerance (initially one output video frame plus one encoded audio-frame duration); report exact measured drift and fail beyond it. Research target-duration checks must include both nominal timeline duration and measured render duration; a target boundary ambiguity becomes `review`, not a fabricated pass. Identical inputs/versions/preset should yield equivalent decoded media, but cross-platform encoded byte identity is not a correctness requirement.

## Agent Workspace, persistence, and reversibility

An Agent Workspace is a local candidate branch from an immutable accepted revision. It references the same immutable assets and segments, stores independent candidate snapshots and optional contract/plan artifacts, and carries a policy hash. Candidate operations/previews never advance the accepted project head. Creation and initialization are trusted lifecycle actions; all subsequent timeline edits flow through `EditOperation` and the kernel.

Proposed runtime layout:

```text
.aether/projects/<projectId>/
  assets/<sourceHash>.<ext>
  ingestion.json
  transcript.json
  snapshots/<contentHash>.json
  accepted-head.json
  workspaces/<workspaceId>/
    head.json
    receipts/<receiptId>.json
    traces/<attemptId>.json
    contract.json             # optional future orchestration artifact
    plan.json                 # optional future orchestration artifact
  artifacts/<artifactId>/
    manifest.json
    preview.mp4              # or render.mp4
    verification.json
```

Use canonical JSON for project content hashing; exclude timestamps, host paths outside the normalized project path, and mutable revision metadata. Store wall-clock information in trace metadata only. Write immutable snapshots and receipts first, then atomically replace the candidate head manifest referencing those durable artifacts. The head manifest is the commit point. Unreferenced files from an interrupted write are recoverable/orphaned artifacts, not accepted state. Validate references/hashes on restart and never replay a partly written journal. Keep V0.1 to one local writer process, with a filesystem lock that rejects a second writer and documents recovery; no distributed locking.

Every accepted batch records validated before/after content snapshots. Full snapshots are inexpensive for this small IR and avoid brittle inverse commands. Undo asks the trusted workspace lifecycle service to restore the receipt's before-content through a kernel-owned restore path that revalidates schema, invariants, immutable assets, and policy. Redo restores its after-content. This path accepts only stored trusted receipts, is unavailable as an arbitrary agent edit tool, and cannot accept model-authored snapshots.

Revision numbers always increase, including undo/redo; content restoration is exact while revision metadata records a new event. A new edit after undo clears the redo chain. Batch ID plus payload digest provides idempotency: an identical retry returns the original result without reapplying, even if the head has since advanced; a reused ID with different content fails. Mark a replay result so callers know it is historical and must refresh the timeline. Unknown IDs and stale expected revisions fail before mutation. Keep rejected attempts for invalid-operation and repair metrics.

Promotion is an explicit trusted CLI command, never an automatic agent capability. Revalidate a non-empty candidate and its verification results against the exact candidate/policy hashes. Require the accepted head to match the workspace base; reject stale promotion rather than automatically merging. Deterministic failures block promotion, and unresolved semantic checks remain visibly `review`. Promotion records review disposition and atomically advances the accepted head to kernel-produced content. Discard closes a workspace without changing accepted state. Artifacts from old revisions are retained with their originating hashes and cannot pass as verification of a newer revision.

## Shared agent tool surface

Both future conditions receive the same schemas, permissions, error responses, retrieval limits, renderer presets, and instrumentation:

- `get_timeline(workspaceId)`: bounded clip listing, revision/hash, duration, gaps, and pagination.
- `get_contract(workspaceId)`: the common trusted run policy and raw request. An AETHER-authored `EditContract` is an orchestration artifact supplied only by its planner; this tool must not make the baseline produce one as a prerequisite.
- `search_transcript(workspaceId, query, limit, cursor?)`: deterministic local lexical search with source-range evidence and bounded excerpts.
- `inspect_segment(workspaceId, segmentId, contextMs?)`: one segment plus bounded neighboring source context; return omitted-context information.
- `preview_range(workspaceId, timelineRange)`: bounded render artifact at the current revision/hash.
- `apply_edit_batch(EditBatch)`: only mutation gateway, including all five operations with the same semantics.

Optional caller-supplied rationale is trace metadata and never changes validation or privileges. Read results are detached copies. Tool request schemas have explicit limits on batch size, search results, context, and preview length, chosen and recorded identically for both paths. Bound model inputs through retrieval; do not attach the entire transcript/video to every call. The trusted developer can inspect local files, but future model runtime callbacks expose only this tool surface, never filesystem or process APIs.

## Deterministic verification and testing strategy

Core correctness tests require only tiny JSON fixtures and no model or FFmpeg installation. Tests are evidence of behavior, not assertions mirroring reducer internals. Record rejected operations separately from applied operations; never drop violations because invalid candidates were prevented.

| Layer | Required behavioral evidence |
| --- | --- |
| Schemas/ingestion | Malformed/unknown fields, unsafe integers, duplicate IDs, missing references, transcript overlap/out-of-bounds, invalid duration, ambiguous streams, and timestamp-origin mismatches are rejected. Same fixture input gives stable hashes/segment IDs. |
| Five operations | Exact expected intervals/IDs for split/trim/delete/ripple-delete/move; boundary splits, extending trims, missing IDs, overlaps, stale references, and disallowed edits fail without mutation. Deletion/ripple gap examples above must differ as specified. |
| Protection | Splitting preserves protected coverage; full/partial removal by trim/delete/ripple-delete fails. Coverage is computed over a union of source intervals, not clip IDs. Moves preserve coverage while semantic verification may still require review. |
| Transactions/history | Failure on operation N leaves original content/head/history unchanged. Successful batches replay deterministically. Apply -> undo restores the exact before-content hash; redo restores after-content. New edits clear redo; duplicate batch retries do not reapply. |
| Persistence/isolation | Editing, rendering, undoing, and discarding candidate A leaves accepted state and candidate B unchanged. Fault injection before/after head replacement yields a valid old or new head. Corrupt snapshots are rejected; stale promotion fails. |
| Tool boundary | No direct snapshot/path/filter payload is accepted; mutation goes through the same dispatcher. Reads cannot mutate stored state. Limits and paginated evidence are deterministic. |
| Verification | Target-duration and hard/soft range coverage return pass/fail/review with evidence and correct hashes. Semantic checks without a configured evaluator return review. Stale evidence cannot authorize promotion. |
| Media integration | Generate a short marked color/tone clip locally using a fixed recipe, with a known timestamped transcript. Split/trim/ripple/reorder/gap previews contain the expected decoded markers and audio, correct order, gap behavior, and measured duration within declared tolerance. Cover a source without audio and nonzero presentation origin. |
| Shared-path smoke test | Two scripted adapters start from identical accepted content/policy, use identical tool definitions/limits, and submit the same operations. They produce equal candidate content and deterministic verification. Accepted state remains unchanged until explicit promotion. |

Add fixed-seed randomized short operation sequences to test invariant preservation and undo equality across combinations; report the seed on failure. Run each operation against beginning/middle/end clips and protected intervals crossing split boundaries. Use deterministic IDs and injected clocks in unit fixtures. Compare content hashes and decoded media properties, not wall-clock times or encoded byte hashes across machines.

FFmpeg integration tests must be separate from unit tests and required for foundation acceptance. A missing binary produces a clearly recorded unmet acceptance check rather than a silently skipped success. Do not run tests or generate media during this planning-only task.

## How Experiment 001 plugs in later

V0.1 reserves interfaces and traces; it does not implement model planners, a compiler, semantic judging, or human evaluation collection. A later runner will inject a planner callback that can retrieve through the common tools and submit `EditOperation` batches. The Baseline callback directly follows the raw request. The AETHER callback constructs its contract and plan, then compiles them to the same batches. No kernel, rendering, or validation fork is permitted.

Before an actual comparison, freeze a fixture bundle containing the 3-8 minute talking-head source, timestamped transcript, raw request, trusted required/protected source annotations, and evaluation criteria. Bind the important junior-engineer caveat using trusted source ranges for both conditions. Do not derive evaluation labels only from AETHER's contract. Keep the initial accepted IR and immutable common enforcement policy byte-equivalent across both workspaces. The policy read tool exposes the same information to either condition, while the structured orchestration layer remains the independent variable.

Freeze model/version, sampling parameters, available reads/edits, limits, kernel, media assets, renderer preset/version, verifier criteria/context rules, and budget policy. Track tokens/tool calls, repairs, total runtime, and cost across all AETHER planning stages and baseline calls. Record deviations and unavailable metrics explicitly as unavailable, not zero. Use matched retry/repair allowances and identical invalid-operation feedback; do not give AETHER privileged error repair or hidden protected annotations. Log attempt and completion events with request/response hashes and operation outcomes, distinguishing invalid operations, source-range violations, hard-constraint violations, applied-operation count, and retries/repairs.

Deterministic verification measures target duration and protected/required source coverage. Later semantic checks evaluate central argument, caveat, coherence, and meaning distortion using the same relevant source context around edited material for both conditions. Passing range retention does not establish semantic preservation. Keep verifier inputs independent of planner identity and reasoning, and attach evidence to check results. ## Decisions proposed for review

| Choice | Reason and consequence |
| --- | --- |
| One audiovisual lane with explicit clip positions | Makes the five operation meanings testable; supports gaps while excluding overlap/mixing. |
| Integer milliseconds and half-open intervals | Simple schema/math and deterministic undo; actual frame/audio alignment needs measured tolerance. |
| Pure Core kernel and trusted Workspace persistence | Keeps edit authority centralized and makes candidate isolation testable. |
| Atomic batches and full-content snapshot undo | Small local IR makes correctness preferable to inverse-operation complexity; history consumes more disk. |
| Shared immutable RunPolicy separate from AETHER's contract | Both conditions enforce the same trusted hard constraints; planner-generated intent cannot weaken evaluation. |
| Imported transcript cues as initial semantic segments | Avoids ASR/segmentation confounds; semantic granularity is limited by the provided transcript. |
| Fixed local FFmpeg re-encode preset | Predictable cut/render behavior; render latency and frame quantization must be logged. |
| Five foundation packages plus one CLI | Separates mutation, media subprocesses, persistence, tools, and checks without cloud/service infrastructure. |

## Unresolved architectural questions and tradeoffs

These questions are recorded for review, with defaults so a later implementer can proceed if approved. None authorizes implementation in this task.

1. **Time resolution and supported source timing.** Default to integer milliseconds and normal SDR timing with explicit stream origin handling. Review whether rational frame ticks or integer microseconds are necessary for the chosen research source. VFR with uncertain duration/alignment should be rejected with evidence in V0.1 rather than silently normalized. A later timing change needs schema/version and render-test updates.
2. **Trim and move semantics.** Default to non-ripple trim anchored at existing timeline start and absolute non-ripple move. This keeps each operation explicit, but compilers must use batches and temporary free intervals for reordering. Confirm this modest tool surface is sufficient for both conditions before running Experiment 001; any added compound edit must be equally available.
3. **Hard semantic protection versus coverage.** Default to trusted fixture ranges immutable across both paths, full union coverage enforced by the kernel, and semantic meaning judged separately. Confirm annotation procedure and caveat-context boundaries before the actual experiment; neither clip identity nor retained words alone prove meaning.
4. **Baseline access to constraints.** Default `get_contract` returns the shared run policy/raw request without requiring an AETHER representation. Confirm whether future model inputs expose explicit range bindings, and expose the same bindings in both conditions if used. Record this choice as a research control.
5. **Final acceptance of semantic review.** V0.1 promotion requires passing deterministic checks and an explicit recorded human disposition of review results. A later research plan must specify semantic evaluator and blind review protocol; do not silently turn review into pass.
6. **Source and artifact storage.** Default to copied immutable local media and full JSON snapshots. This uses more space than references/deltas but avoids mutable source paths. Revisit only if actual fixture size or history makes it impractical; no database is currently warranted.
7. **Rendering normalization and tolerances.** Select the fixed preset and frame/audio tolerance using a representative source at implementation time, document versions, and use it identically across paths. Unsupported rotation/HDR/multistream inputs fail. Decide explicit VFR normalization only with source-mapping evidence and plan review.
8. **Research budgets and repetitions.** Foundation traces include all calls, attempts, timings, and optional cost fields. Matched resource limits, order randomization, trial count, cost availability, semantic judge setup, and stopping rules belong to the later Experiment 001 plan; this document does not prescribe or change the research methodology.
